One sentence, at most 200 characters, explaining the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things they already know: post offices, libraries, market squares, and roads.

## Run it

```sh
python3 main.py
```

The program writes the sentence to `/output/entry.txt`.
